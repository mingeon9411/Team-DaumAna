### Oracle Database 21c Express Edition(XE) 완벽하게 삭제(Clean Uninstall)하고, 새로 설치 및 초기 구축하는 과정을 단계별로 정리.


★1단계: 기존 Oracle XE 21c 완벽 제거 (Clean Uninstall)

1. 오라클 서비스 중지

Win + R을 누르고 services.msc 입력 후 엔터.

Oracle로 시작하는 모든 서비스(예: OracleServiceXE, OracleOraDB21Home1TNSListener 등등)를 마우스 우클릭 후 [중지].


2. 제어판에서 프로그램 삭제

제어판의 [프로그램 추가/제어]에서 Oracle Database 21c Express Edition을 찾아 [제거]를 진행.


3. 레지스트리 편집기(Registry) 잔재 삭제 (★가장 중요★)

Win + R을 누르고 regedit 입력 후 엔터.

아래의 세 경로를 찾아 Oracle 관련 폴더를 통째로 삭제.

HKEY_LOCAL_MACHINE ➔ SYSTEM ➔ CurrentControlSet ➔ Services ➔ Oracle...로 시작하는 모든 키 삭제

HKEY_LOCAL_MACHINE ➔ SYSTEM ➔ CurrentControlSet ➔ Services ➔ EventLog ➔ Application ➔ Oracle...로 시작하는 모든 키 삭제

HKEY_LOCAL_MACHINE ➔ SOFTWARE ➔ ORACLE 폴더 삭제


4. 환경 변수(Environment Path) 정리

"시스템 환경 변수 편집"으로 이동 ➔ [환경 변수] 클릭.

Path 변수에서 Oracle 설치 경로(예: C:\app\...)와 관련된 항목이 남아있다면 선택 후 [삭제].


5. 설치 폴더 및 기본 잔재 파일 강제 삭제

PC를 재부팅. (기존 파일 Lock 해제 목적)

재부팅 후, 다음 폴더들을 직접 찾아가서 통째로 삭제.

C:\app (오라클 기본 설치 경로)

C:\Program Files\Oracle


6. 완료 상태 확인: 이제 PC는 오라클이 한 번도 설치되지 않은 깨끗한 상태.



★2단계: Oracle XE 21c 새로 설치하기

1. 설치 파일 준비

다운로드해 둔 Oracle Database 21c Express Edition 설치 압축 파일을 풀고 setup.exe를 관리자 권한으로 실행.


2. 설치 마법사 진행

라이선스 동의 후 Next를 누룬다.

설치 경로(Destination Folder) 설정: 가급적 기본 경로(C:\app\사용자명\product\21.0.0\dbhomeXE)를 유지하거나, 

전사적으로 C:\oracle\product\21.c와 같이 직관적인 공통 경로를 지정.


3. 관리자(SYS, SYSTEM, PDBADMIN) 비밀번호 설정

💡 중요: 이 비밀번호는 DB 최고 관리자 계정의 비밀번호가 됨. 팀 공통 비밀번호(ctrlaltelite)로 통일.


4. 설치 완료 및 포트 확인

Install을 누르고 완료될 때까지 대기. (약 10~20분 소요)

완료 화면에 나오는 접속 URL 정보(특히 localhost:1521/XE)를 캡처하거나 메모한다.


★3단계: 신규 데이터베이스(DB) 환경 구축 및 설정: 설치가 끝났다면 프로젝트를 진행할 수 있도록 관리자 계정에서 사용자 계정(스키마)을 파내고 권한을 부여.

1. CMD(명령 프롬프트)를 관리자 권한으로 열기


2. 관리자 계정(SQL*Plus) 접속

SQL>  sqlplus sys as sysdba

(비밀번호를 입력하라고 나오면 2단계에서 설정한 공통 비밀번호(:ctrlaltelite)를 입력)


※ 21c의 멀티테넌트(C##) 우회 설정 (만약 C##을 사용하지 않으려면)

오라클 12c 버전 이후부터는 계정명 앞에 C##을 붙여야 하는 번거로움이 있는데, 

예전 방식대로 깔끔하게 계정을 생성하려면, 접속 후 가장 먼저 아래 명령어를 실행.

SQL>  ALTER SESSION SET "_ORACLE_SCRIPT" = TRUE;


3. 팀 공통 프로젝트 계정(User) 생성 및 권한 부여

우리 DB의 계정명을 C##ELITE, 비밀번호를 rewq4321로 설정하는 스크립트.


-- 1. 계정 생성 (계정명: C##ELITE / 비번: rewq4321)

SQL>  CREATE USER C##ELITE IDENTIFIED BY rewq4321;


-- 2. 테이블 스페이스 권한 및 기본 용량 할당 (기본 권한 부여)

SQL>  ALTER USER C##ELITE DEFAULT TABLESPACE users QUOTA UNLIMITED ON users;


-- 3. 접속, 개발, 관리자 권한 부여

SQL>  GRANT CONNECT, RESOURCE, DBA TO C##ELITE;


4. 최종 접속 테스트

SQL*Plus 창을 닫고, 새로 만든 계정으로 접속이 잘 되는지 확인.

SQL>  sqlplus C##ELITE/rewq4321

만약 Connected to: 메시지가 뜨면 정상적으로 DB 구축이 완료된 것.

💡 비밀번호/계정명 통일: 구축할 계정명과 비밀번호를 명확하게 미리 정의해 주면, 나중에 파이썬이나 JAVA로 연동 코드를 작성할 때 

     소스코드를 공유해도 커넥션 스트링(db_url)을 각자 수정할 필요가 없어 협업 효율이 극대화됨.
