1. 장바구니 상품 추가 (POST 테스트) : http://127.0.0.1:8000/api/shop/cart/

사용자가 상품 상세 페이지에서 '장바구니 담기'를 눌렀을 때 서버로 보내는 데이터 양식.

아래 JSON 코드 중 product와 product_option에는 이전 단계(Admin)에서 생성되었던 실제 ID(Primary Key, 정수형 숫자)를 입력하여야 데이터 무결성 에러(외래키 에러)가 나지 않음.


JSON

{
    "product": 1,
    "product_option": 2,
    "quantity": 2
}




2. 장바구니 수량 변경 (PUT 또는 PATCH 테스트)

이미 장바구니에 담긴 아이템의 수량을 변경할 때 테스트하는 양식.

보통 특정 장바구니 아이템의 고유 ID(예: /api/shop/cart/5/)로 요청을 보내거나, 현재 경로 그대로 보낸다면 기존 데이터를 덮어쓰는 형태로 처리.


JSON

{
    "product": 1,
    "product_option": 2,
    "quantity": 5
}


테스트 방법: 수량을 5로 늘려서 보낸 뒤, 상단 결과창에 HTTP 200 OK 혹은 HTTP 201 Created가 뜨며 데이터가 업데이트되는지 확인.
