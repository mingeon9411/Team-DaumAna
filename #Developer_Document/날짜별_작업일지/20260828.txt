➡️ OAuth2 리다이렉트(app.frontend-url)는 값 하나로 고정해야 하지만, CORS는
   로컬 dev(nip.io)와 배포(jipdaum.life)를 동시에 열어둘 필요가 있어
   app.cors-allowed-origins(콤마 구분 목록)를 별도로 받도록 분리(커밋 26bac46)
➡️ 그런데 EC2의 application.yml(gitignore 대상)엔 이 새 키가 아직 없어서,
   기본값 없는 @Value가 컨텍스트 초기화를 실패시켜 컨테이너가 못 뜨고,
   docker run이 fire-and-forget이라 GitHub Actions는 success로 표시된 채
   실제로는 프로덕션 전체 API가 502로 막혀 있던 사고 발생 — 값이 없으면
   기존 app.frontend-url로 폴백하도록 중첩 플레이스홀더 기본값을 추가해
   해결(커밋 e24307d)
➡️ 상세 내용은 jipdaum-spring 저장소의 같은 날짜 작업일지 참고
