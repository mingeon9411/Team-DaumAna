✅ Cloudflare Pages가 최신 커밋을 계속 못 물어가던 문제 진단/수정
   - jipdaum.life에서 "hCaptcha has failed to initialize" + 콘솔에
     "Missing sitekey" 확인 — VITE_HCAPTCHA_SITE_KEY가 Cloudflare Pages
     프로젝트 환경변수에 미등록 상태였음(PASS 전환 때 .env.example에서 지워진 여파)
   - 환경변수를 등록해도 여전히 동일 에러 → Vite 환경변수는 빌드 시점에
     번들에 굳어지므로 재빌드 없이는 반영 안 됨을 확인
   - 확인해보니 Cloudflare Pages가 main의 새 커밋을 계속 못 물어가고
     예전 커밋(4ddaeab)에 멈춰있었음 — Cloudflare Pages 기본 빌드 Node
     버전(보통 18.x)이 vite 7의 요구사항(engines: node ^20.19.0 ||
     >=22.12.0)을 못 맞춰서, Cloudflare Pages로 이관(hCaptcha→PASS 교체와
     같은 커밋에서 진행)된 이후 모든 빌드가 계속 실패했을 가능성이 높다고 판단
   - frontend/.nvmrc(20) 추가 + package.json에 engines.node(">=20.19.0")
     명시 — Cloudflare Pages가 올바른 Node 버전으로 빌드하도록 유도
   - 재배포 성공 여부는 확인 대기 중
